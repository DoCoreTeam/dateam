## 목표
- 견적 옆 글 상자에 생각나는 대로 쓰고 3초 멈추면 표가 고쳐진다, 줄을 더하고 고치고 지우며 쓴 글은 견적과 함께 남는다
- 금액, 수량과 단위, 등급, GPU 모델, 품목 이름과 별칭은 규칙이 먼저 읽고 못 읽은 줄만 AI가 조건으로 읽는다, 금액은 엔진만 센다
- 틀린 칸은 규칙이 고쳐 두고 「자동으로 고친 값」에 줄마다 되돌리기가 붙는다, AI가 안 돼도 글은 남고 규칙과 엔진은 돈다

## 범위 밖
- ENT 전환 구축을 계약 기록과 잇는 것 (기획서 솔루션 가격표 「놓치시기 쉬운 것」 7, 기획서가 이번 범위 밖으로 둠)
- 파일로 채우기의 흐름 자체 (기획서 「쓰는 길 셋」 표가 그대로 둔다고 함)
- 견적 공개 API 모양 변경

## 완료 정의
- pnpm typecheck, pnpm test, pnpm build 통과
- 숙명여대 시험 문장을 AI 없이 규칙만으로 읽은 줄 비율 80% 이상, 시험에서 단정
- 같은 글 두 번이면 AI 호출 1번, 표 변화 0 (시험)
- 사람이 고친 칸은 다시 정리해도 남음 (시험과 실브라우저)
- 실브라우저: 편집기에 기획서 숙명여대 글을 쓰고 3초 멈추면 표가 채워짐, 저장 뒤 다시 열면 글이 남음, 1280px 와 390px
- 사용자 노출 문자열은 lib/terms 에서 가져옴
