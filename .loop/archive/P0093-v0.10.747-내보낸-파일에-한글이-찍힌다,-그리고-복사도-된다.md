## 목표
- 내보낸 PDF·이미지에 **한글이 실제로 찍힌다** — 지금은 프로덕션에서 한글만 통째로 빈칸으로 나온다
- 회의록을 **클립보드로 복사**할 수 있다 — 파일로 받지 않고 바로 붙여넣는 길

## 근거 (실측 2026-09-30)
- `@sparticuz/chromium@149` 이 배포본에 싣는 글꼴은 `fonts/Open_Sans/{Regular,Bold,Italic}.ttf` **셋뿐**이다
  (`bin/fonts.tar.br` 압축 해제 결과). 한글 자형이 서버에 **하나도 없다**
- 문서 CSS 는 `-apple-system, BlinkMacSystemFont, 'Malgun Gothic', 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif`
  를 부른다 — 로컬 macOS 에서는 다 되지만 람다에는 하나도 없어 폴백이 Open Sans 로 떨어진다
- 그래서 숫자와 로마자(Onedrive·SaaS·WBS·VPN·Dooray)만 찍히고 한글은 전부 빈칸이다

## 범위 밖
- 미리보기(iframe) 에 글꼴을 심는 것 — 미리보기는 **사용자 브라우저**가 그리므로 한글이 이미 나온다.
  `sandbox=""` iframe 은 불투명 출처라 `/fonts/*.woff2` 가 교차 출처 글꼴이 되어 CORS 에 막히고,
  data: 로 심으면 부모 CSP 의 `font-src` 를 건드려야 한다. 고장난 곳만 고친다
- 글꼴 파일 교체·추가 — 저장소에 이미 있는 Pretendard 조각(`public/fonts/pretendard/`, 92개)을 그대로 쓴다
- 클립보드 복사를 회의록 밖(AI 채팅 등)으로 넓히는 것 — 이번 지시는 회의록이다

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- 헤드리스 크로미움이 문서를 그릴 때 `Pretendard Variable` 이 **loaded** 상태이고,
  한글만 담긴 문자열의 렌더 폭이 글꼴 없이 그렸을 때와 다르다(자형이 실제로 쓰였다는 증거)
- 회의록 내보내기 창에서 복사 단추 한 번으로 서식 있는 회의록이 클립보드에 담긴다
- 같은 구멍을 가진 내보내기 창구 셋이 모두 고쳐진다(회의록, AI 채팅 내보내기 둘)

### I05 배포본에서 자형 경로를 **찾아서** 쓴다
상태: 통과
모드: 경량
범위: apps/web/lib/export/embed-korean-font.ts, apps/web/lib/export/font-subset.ts, apps/web/lib/export/font-subset.test.ts
감사 기준:
- `public/` 자리를 **하나로 가정하지 않는다** — 후보를 차례로 열어 실제로 있는 것을 쓴다. 지금은 cwd 가 `apps/web` 으로 끝나는지로만 갈라, λ 의 cwd 가 `/var/task` 이고 파일이 `/var/task/public` 에 있으면 없는 경로를 짚는다
- 후보를 다 못 찾으면 **어디를 찾아봤는지**가 기록에 남는다 — 「없다」만으로는 다음 사람이 또 헤맨다
- 찾은 자리는 한 번만 찾고 기억한다(호출마다 파일 시스템을 훑지 않는다)
- 이 기계에서 실제로 찾아지는 것을 확인한다(조각 92개가 열린다)
- 보안: 후보 목록은 **저장소 안 고정 경로**뿐이다 — 밖에서 온 값이 경로에 안 섞이는 것을 확인한다(경로 조작 여지 0)
