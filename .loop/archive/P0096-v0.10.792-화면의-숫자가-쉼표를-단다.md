# PLAN newAX: 화면의 숫자가 쉼표를 단다
플랜 ID: P0096
플랜 버전: v0.1.3

목표 버전: v0.10.792

시작 커밋: 74ae43f7

## 목표
- 화면에 뜨는 숫자가 천 단위마다 쉼표를 단다, 지금은 AI 트레이딩 가격이 「1086.44」로 나와 자릿수를 세어야 함
- 숫자를 굽는 자리를 한 곳(`lib/ui/number-format.ts`)으로 모은다, 지금은 가격 포맷터만 둘이고 둘 다 쉼표가 없음
- 가드가 세서 다음에 새로 만든 숫자가 다시 맨몸으로 나가지 않게 한다

## 범위 밖
- 기계가 읽는 문자열(사유 코드 `ev_below_minimum:0.12`, 로그 키, API 응답 값)은 안 건드림, 쉼표가 섞이면 파싱이 깨짐
- 백분율·배수·R 값처럼 1000 을 넘을 수 없는 값의 표기 규칙 변경(자릿수·반올림)은 안 함, 쉼표만 다룸
- 금액 입력칸(`MoneyField`)은 이미 `groupDigits` 로 쉼표를 달고 있어 그대로 둠
- 숫자를 억·만으로 줄여 쓰는 자리(`RadarRules`·`GcubeSyncBadge`·딜 합계)는 줄인 뒤 값이 1000 미만이라 그대로 둠

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- AI 트레이딩 현황에서 지금 가격·주문 카드·차트 세로축이 전부 「1,086.44」 꼴로 뜸 (실브라우저)
- 1000 이상 값을 넣었을 때 쉼표가 나오는지를 시험이 **함수를 불러서** 확인
- 가드를 일부러 깨뜨려 실패를 확인한 사실이 pass 기록에 남음

## 참조
- 이미 있는 자릿수 묶기: `apps/web/lib/ui/money-format.ts` 의 `groupDigits`
- 이미 쉼표를 다는 자리: `apps/web/lib/gpu/format-price.ts`(`fmtKRW`·`fmtUSD`), `lib/trading/position-labels.ts` 의 `wonText`
- 실측 2026-09-30: 사용자 노출 `toFixed(` 65파일, 그중 트레이딩 23파일, 1000 을 넘을 수 있는 자리는 가격·AI 비용·GPU 단가
