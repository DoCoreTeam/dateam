## 목표
- 이름은 개인정보다, 기준은 이미 서 있는데 가림 규칙이 이름만 안 잡고 있다
- 이름을 추측으로 찾지 않는다, 우리가 이미 가진 이름을 쓴다, 그래서 오탐이 없다
- 명함과 리드와 회의 전사에 사람 이름이 그대로 실려 나가던 것을 멈춘다

## 범위 밖
- 우리가 모르는 사람의 이름, 아는 이름부터 막고 모르는 것은 목록에 더해 가며 좁힌다
- 주소와 생년월일 같은 다른 개인정보 항목
- 이미 나간 기록을 되돌리는 일

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- 아는 이름이 들어 있으면 가려져 나가고 답에서 되돌아온다
- 이름을 추측하지 않는다, 목록 밖 글자는 안 건드린다
- 이름 목록을 안 주면 전과 똑같이 동작한다, 즉 기존 호출처가 안 깨진다

## 항목

### I01 아는 이름을 가리는 규칙
상태: 통과
모드: 중량
범위: packages/ai-gateway/src/mask.ts, packages/ai-gateway/src/mask.test.ts (신규), packages/ai-gateway/src/index.ts, apps/web/package.json
감사 기준:
- 이름 종류를 PiiKind 에 더하고, 규칙이 아니라 **주어진 목록**으로 찾음
- 목록이 없으면 전과 같이 동작함, 기존 시험이 그대로 통과
- 긴 이름부터 먼저 가려 부분 일치로 잘리지 않게 함 (김도현 과 김도 가 같이 있을 때)
- 같은 이름은 같은 자리표를 받고 왕복이 원문을 잃지 않음
- 목록 밖 글자는 안 건드림, 단정으로 확인
- 두 글자 이하 이름은 안 가림, 흔한 낱말과 겹쳐 뜻을 부수기 때문 (그 판단을 주석과 단정으로 남김)
- node --test 통과, 등재 후 총 테스트 수 증가 확인
의존: 없음

### I01a ES5 로 떨어지는 근원을 고친다
상태: 통과
모드: 중량
범위: apps/web/tsconfig.json
감사 기준:
- 실측 근거를 notes 에 적음: TS2802 를 이번 판에서 네 번 밟았고(js-download, review.ts, mask.ts, 그리고 v0.10.0 의 첫 건) 매번 Array.from 으로 피했음, 근원은 tsconfig 에 target 이 없어 ES5 로 떨어지는 것
- target 을 올려도 되는 이유를 적음: tsc 는 noEmit 이라 타입 검사에만 쓰이고, 올리면 쓸 수 있는 것이 늘어날 뿐 줄지 않음, 빌드 산출물은 Next 가 자기 target 으로 만듦
- 다른 세션이 이 파일을 고치는 중이면 손대지 않고 보류로 남김
- target 을 올린 뒤 Array.from 으로 피해 둔 자리가 여전히 통과하는 것을 확인 (되돌리지는 않음, 그것은 별 일)
- pnpm tsc 와 pnpm build 통과
의존: I01
