## 목표
- 관리자 시스템 설정이 다른 설정 화면 셋과 같은 그릇에 담겨 검색 칸·분류 탭·빈 상태가 같아짐
- 카드 위에 한 겹 더 있던 섹션 제목이 사라지고 카드가 곧 찾는 단위가 됨
- 「공용 그릇에 담았는가」를 기계가 재게 되어 다섯째 설정 화면이 또 갈리지 않음

## 범위 밖
- 각 설정 카드의 내용과 동작 (필드·저장·연결 확인은 그대로)
- 다른 설정 화면 셋 (콘텐츠 인텔리전스·영업 CRM·RFP 관리자)
- AI 키 줄의 단추 모양
- 설정 페이지의 서버 조회 구조

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- /admin/settings 에 검색 칸이 뜨고 카드 이름으로 걸러짐 (실브라우저)
- 관리자 설정 화면에 SegmentedTabs 직접 호출과 SettingsSection 이 남아 있지 않음
- 설정 화면 넷이 전부 공용 그릇을 쓰는 것을 가드가 단정
- 사용자 노출 문자열은 전부 lib/terms 또는 카드 부품에서 옴
- 설정값은 env 추가 없이 DB 저장 + UI 관리 (해당 없음, 새 설정 없음)
