발견 사항 넷

1. **전역 CSS 가 `img` 를 `display: block` 으로 둔다.** 그래서 도장이 상호 «아래»로 내려갔다 —
   그려지기는 해서 「안 찍힌다」가 아니라 「자리가 틀렸다」로 나타났고 원인이 잘 안 보였다.
   `.seal { display: inline-block }` 으로 고정
2. **`.gitignore` 의 `*.png` 가 e2e 픽스처를 막는다.** 파일로 두면 새 클론에서 시험이
   「화면이 깨졌다」가 아니라 「파일이 없다」로 죽는다. 스펙 안 버퍼로 바꿈
3. **굳은 그림 가드가 코드 «모양»에 묶여 있었다** (`logoAssetHash ? readAsset(...)` 문자열).
   규칙은 그대로인데 직인이 늘어 모양이 바뀌자 실패했다. 값이 어디로 가는지를 보도록 고치고 직인까지 덮음
4. **`loop pass --files` 는 쉼표 구분이다.** 공백으로 준 I01·I02 에서 파일이 빠졌다
   (I01 은 트리 전체가 실렸고, I02 는 코드 3파일이 빠져 I03 커밋에 실었다)

일부러 깨 본 가드 넷 (LOOP.md 7절 S6)

- 도장과 문구를 함께 내는 판 → e2e 의 `toHaveCount(0)` 이 1 을 받아 실패
