## 목표
- teamda crm quote export 와 공개 API 관문(/api/public/v1/crm/quotes/{id}/export)으로 부른 견적서 내보내기가 웹 세션과 같은 PDF PNG 를 돌려줌
- 관문이 연 키 주인 문맥 안에서만 그 사람 세션을 머리 없는 브라우저의 인증 쿠키로 심고, 쿠키로 부른 웹 경로는 그대로임
- 2단계 인증을 켠 키 주인은 머리 없는 브라우저가 /mfa 에서 멈추므로 60초 기다리지 않고 읽을 수 있는 말로 바로 거절함

## 범위 밖
- 다른 서버 렌더 창구(회의록 내보내기 등)의 키 경로, 이번 결함은 견적서 내보내기 하나
- 2단계 인증 키 주인의 내보내기 자체를 되게 하는 일, 키로 aal2 세션을 만들 길이 없음 (거절 문구로 안내)
- 마이그레이션 318 적용, 관문의 기존 대체 경로를 그대로 씀

## 완료 정의
