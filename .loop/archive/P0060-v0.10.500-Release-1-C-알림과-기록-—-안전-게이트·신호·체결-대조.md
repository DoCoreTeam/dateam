## 목표
- 안전 게이트 열둘과 신호 규칙 열이 실제로 돌고, 그 순서를 어기면 신호가 못 나감 (M2)
- 알림이 아웃박스를 지나 **한 번만** 나가고, 실패해도 사라지지 않음 (§14.3)
- KIS 계좌와 우리 기록을 대조해 어긋나면 신호를 멈춤 (SG-04)
- 봉 마감 → 발송 → 열람 → 주문 → 체결 네 구간 지연이 기록에 남음 (§14.2)
- **검증 관문을 통과하기 전에는 알림을 켤 수 없음** (C4)

## 범위 밖
- Release 2·3 (Gemini 지식 카드·AI 운영자) — 다음 플랜
- Release 4 자동 주문 — 명세가 별도 설계·승인이라 적고 이 문서에 설계가 없음, M1 가드 그대로
- 실제 알림 켜기 — 섀도 5거래일과 관문 통과가 먼저다(§3.2)
- 푸시 발송 장치 — 이 저장소에 없다, 앱 안 알림 행으로 하고 ASSUMPTIONS 에 적음

## 완료 정의
- pnpm tsc --noEmit, pnpm test, pnpm build 통과
- 배선 가드 초록 — 만들고 안 부르는 자리 0
- 주문 API 0건 유지 (M1 가드), 계좌 조회는 **조회만**
- 알림이 게이트·규칙을 안 지나고 나가는 길이 0개임을 가드가 셈 (M2)

### 5 발견 사항 (고친 것)

1. **주문 금지 가드에 구멍** — 규칙이 `(TTTO|JTCE|VTTO)\d{4}U` 라 실전 야간 주문 `STTN1101U` 와
   정정취소 `TTTN1103U` 를 안 잡았다. 앞머리가 아니라 **끝 `U`** 로 판정하게 고쳤다
2. **알림 유일 키가 신호 없는 알림을 하나도 안 막았다** — `signal_id` 가 NULL 이면 Postgres 에서
   유일 키가 성립하지 않는다. 매분 크론이 같은 손절 확인을 하루 390번 넣었을 것이다. 마이그 284
3. **시험 여섯이 한 번도 안 돌고 있었다** — `package.json` 등재에서 경로를 따옴표 하나에 붙여 써
   셸이 이름 하나로 넘겼다. `lib/ui/test-registry.test.ts` 가 잡았다
4. **재시도 간격을 잴 수 없었다** — 알림 표에 마지막 시도 시각이 없어 1분 크론이 상한 다섯을
   5분에 태웠다. 마이그 283
5. **신호 규칙·안전 게이트가 기준값 없이 돌 뻔했다** — 인자로 받게 만들어 뒀는데 그 값을 담을
   설정 키가 레지스트리에 하나도 없었다. 항목 I09a 를 끼워 스물한 개를 등재했다
6. **가드 일곱이 깨뜨려도 초록이었다** — 목록을 비우면 공회전하는 반복, import 만 남아도 통과하는
   이름 검사, 정의 자리를 호출로 세는 검사, 상태 이름을 직접 대입하는 자기 해제. 전부 고치고
   다시 깨뜨려 빨간 것을 확인했다
