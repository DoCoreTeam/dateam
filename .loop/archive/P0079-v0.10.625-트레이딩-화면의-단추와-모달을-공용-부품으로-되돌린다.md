## 목표
- AI 트레이딩 화면의 단추가 다른 화면의 단추와 같아진다
- 모델 고르기가 앱에 이미 있는 공용 모달로 열린다 — 공급자 탭·상태·출시 순서가 다른 화면과 같다
- 없는 클래스 이름을 쓰면 가드가 그 자리에서 잡는다

## 범위 밖
- 모델 목록 새로고침을 트레이딩 화면에서 하는 것 (목록은 관리자 화면이 채우고 트레이딩은 읽기만 함, 사유는 I02 에 적음)
- 설정 항목의 말과 순서 (v0.10.618~624 에서 끝냄)
- 트레이딩 화면의 배치·간격 재설계

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- globals.css 에도 CSS 모듈에도 없는 클래스 이름이 화면 tsx 에 0개
- 모델 고르기 모달이 관리자 화면과 같은 부품 한 벌에서 나온다
- 화면에 한글 문자열을 직접 안 적는다 (@/lib/terms 를 지남)
- 없는 클래스 가드를 일부러 깨뜨려 실패를 확인했다
