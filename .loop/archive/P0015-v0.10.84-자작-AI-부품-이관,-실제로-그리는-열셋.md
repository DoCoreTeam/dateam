목표 버전: v0.10.84

## 목표
- 기획서 9단계의 「자작 부품 이관」을 기준선으로 바꿔치기했던 것을 실제로 한다
- 확신을 그리는 화면이 같은 규칙을 지나게 해 화면마다 다르게 보이지 않게 한다
- 기준선이 세던 숫자를 실제로 내린다

## 범위 밖
- 타입이나 전달만 하는 열둘, 그것은 자작 부품이 아니라 기준선 과대 계상이었다
- 부품의 겉모양을 통일하는 일, 이번은 값을 읽는 규칙을 통일하는 것까지
- 벤더 직접 호출 이관

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- 확신을 그리는 화면이 공용 규칙을 지남
- 기준선이 실제로 내려감
- 화면의 겉모양이 안 바뀜, 즉 기존 시험이 그대로 통과

## 참조
- docs/2026-09-10-ai-common-layer/README.md 9단계
- packages/ai-react/src/value.ts (confidenceView 가 문턱을 인자로 받는다)

## 항목

### I01 기준선을 실제로 그리는 것만으로 다시 잰다
상태: 진행중
모드: 경량
범위: apps/web/lib/policy/ai-component-baseline.json, apps/web/lib/policy/ai-component-baseline.test.ts
감사 기준:
- 실측 정정을 notes 에 적음: 스물다섯 중 실제로 그리는 것은 열셋이고 열둘은 타입이나 전달만 함, 내 첫 기준선이 과대 계상이었음
- 판정을 confidence 가 화면에 그려지는가로 바꾸고, 전달만 하는 것은 안 셈
- 기준선을 열셋으로 내리고 그 사유를 json 에 적음
- 일부러 깨서 늘어남과 줄어듦 둘 다 잡히는지 확인
- 등재된 시험이 그대로 통과
의존: 없음

### I02 숫자로 그리는 다섯을 공용 규칙으로
상태: 대기
모드: 경량
범위: apps/web/app/(crm)/crm/inbox/SuggestionCard.tsx, apps/web/app/(member)/daily/AutolinkSection.tsx, apps/web/app/(member)/dept-tasks/DeptTaskSuggestPanel.tsx, apps/web/app/(member)/meeting-notes/ExtractConfirmModal.tsx, apps/web/app/(crm)/crm/meetings/[id]/MeetingDetail.tsx
감사 기준:
- 다섯이 confidenceView 를 지남, 각 화면의 문턱 숫자는 그 화면 몫으로 그대로 둠
- 확신 없음과 확신 0 을 섞어 그리던 자리가 있으면 고치고 notes 에 적음
- 화면에 보이는 숫자가 안 바뀜, 기존 시험 통과
- tsc 통과
의존: I01
