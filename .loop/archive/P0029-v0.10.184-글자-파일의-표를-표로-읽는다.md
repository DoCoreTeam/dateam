## 목표
- 마크다운 표(`| 품명 | 수량 |`)가 **표로** 읽힌다 — 지금은 글줄이라 구분줄 `| --- |` 까지 AI 에게 그대로 간다
- 같은 자리에서 CSV 도 표로 읽힌다 (콤마·탭·따옴표는 이미 있는 파서를 쓴다)
- 표 격자를 만드는 코드가 **한 곳**이 된다 (지금은 오피스 파서 안에만 있다)
- 견적서 파일 인입에서 「표를 찾지 못해 글줄만 읽었어요」가 **표가 있는 문서에는 안 뜬다**

## 범위 밖
- PDF·이미지 속 표 인식 (그림 경로는 지금 규칙 그대로)
- 마크다운의 다른 문법 (중첩 표·HTML 표·표 안 줄바꿈)
- 견적 계산 규칙, 화면 서식, AI 프롬프트 변경
- 표를 읽었다고 추출 결과를 자동 반영하는 일 (사람이 검수하는 순서는 그대로)

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- 마크다운 표가 든 파일에서 tableCount 가 1 이상이고, 원문 조각에 구분줄이 안 실림
- **표가 아닌 글에서 표를 만들어내지 않음** — 세로줄이 한 줄에 있어도 구분줄이 없으면 표가 아님 (가드)
- 표 격자를 만드는 코드가 한 곳이고 두 파서가 그것을 부름 (가드)
- 견적서 파일 인입 화면에서 실제로 확인 (마크다운 견적서 1회, 스크린샷 근거)
- 기존 RFP·견적 경로의 가드가 그대로 통과 (표가 늘어난 것이 다른 판정을 깨지 않음)

## 항목

### I01 표 격자를 만드는 자리를 하나로
상태: 통과
모드: 경량
범위: lib/rfp/parse/table-grid.ts (신규), lib/rfp/parse/table-grid.test.ts (신규), lib/rfp/parse/office.ts, apps/web/package.json
감사 기준:
- 격자(string[][]) 를 받아 셀 목록·표 글자·표 HTML 을 내는 순수 함수가 한 파일에 있음
- 오피스 파서가 그 함수를 부르고, 자기 안에서 셀 목록이나 표 HTML 을 다시 만들지 않음 (가드 1개)
- 기존 오피스 파서 가드(lib/rfp/parse/office.test.ts)가 그대로 통과 — 표 결과가 한 글자도 안 달라짐
- pnpm --filter web exec node --test lib/rfp/parse/table-grid.test.ts 통과, 등재 후 총 테스트 수 증가
의존: 없음

### I02 마크다운 표를 표로 읽는다
상태: 통과
모드: 경량
범위: lib/rfp/parse/plain.ts, lib/rfp/parse/plain.test.ts
감사 기준:
- 머리줄 + 구분줄(`| --- |`) + 본문줄이 이어지면 표 블록 하나와 IrTable 하나가 생김
- **구분줄은 표에 안 들어감**, 셀 앞뒤 공백은 정리됨, `\|` 는 셀 안의 세로줄로 살아남음
- 세로줄이 있어도 구분줄이 없으면 표가 아님 (문단 그대로), 표 앞뒤 글은 순서를 지켜 문단으로 남음
- 문서 품질 점수의 표 수가 실제 표 수를 반영 (0 으로 굳어 있던 값)
- pnpm --filter web exec node --test lib/rfp/parse/plain.test.ts 통과
의존: I01

### I03 CSV 도 표로 읽는다
상태: 통과
모드: 경량
범위: lib/rfp/parse/plain.ts, lib/rfp/parse/plain.test.ts
감사 기준:
- .csv 는 전체가 표 하나가 됨 (머리줄 포함), 따옴표 안 콤마·줄바꿈이 셀 안에 살아남음
- 구분자는 있는 파서(lib/gpu/csv-intake.ts parseCsv)가 정함 — 콤마·탭 판정을 다시 적지 않음 (가드 1개)
- 표가 못 되면 지금처럼 문단으로 남음 (빈 파일·한 칸짜리)
- 확장자가 .csv 가 아닌데 콤마가 많은 글을 표로 만들지 않음
의존: I02

### I04 견적서 인입에서 확인
상태: 통과
모드: 경량
범위: lib/crm/services/quote-source-text.test.ts, apps/web/e2e/crm-quote-fill.spec.ts

- 실브라우저로 마크다운 견적서를 올려 「표를 찾지 못해 글줄만 읽었어요」가 **안 뜨는 것**을 확인 (스크린샷)
- 읽은 금액이 표 기준과 같음 (지난 판 실측 210,000,000 / 54,000,000 과 같은 값)
- 만든 견적은 지우고 원래 상태로 되돌림
의존: I03
