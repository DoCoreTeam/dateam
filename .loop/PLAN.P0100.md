# PLAN newAX: 화면은 제품의 말을 하고, 기능은 끝까지 이어진다
플랜 ID: P0100
플랜 버전: v0.3.5
상태: 진행중
지시: ins_0158
목표 버전: v0.10.860
작성: 2026-10-01
시작 커밋: 2830d36f

## 목표
- 사용자가 개발 과정에서 한 말(「한눈에」 「자동으로」 「실시간」)이 **기능으로는 남고 화면 문구로는 안 남음**
- 화면 문구가 **판단과 행동에 필요한 것만** 말함 — 홍보 수식어·구현 보고·자기소개가 안 붙음
- 브라우저 기본 대화상자(`alert`·`confirm`)가 **화면에서 사라짐** — 이 저장소는 이미 대체 부품을 만들어 놓고 10곳만 옮긴 채 멈춰 있음
- 이 규칙들이 **글이 아니라 기계로** 지켜짐 — 새 위반은 그 자리에서 막히고 기존 위반은 되돌아가지 못함
- 관리 대상마다 **만들기·보기·고치기·지우기·상태 전환**이 있어야 할 것은 있고, 없어야 할 것은 사유가 적혀 있음
- 목록·수치·알림에서 **근거가 되는 상세로 갈 길**이 있음 — 볼 수 있어야 하는 것이 글자로만 방치되지 않음
- 「코드가 있다」 「빌드가 된다」가 아니라 **실브라우저에서 업무가 끝까지 되고 다시 들어가도 남아 있는 것**으로 완료를 판정함

## 범위 밖
- `lib/changelog/entries.ts` 의 지난 판 문구 — 이미 사용자에게 나간 **발표 기록**이다. 고치면 기록을 고치는 것이 된다 (새로 쓰는 블록은 정책을 따름)
- 정보 구조·메뉴 통합 재편 — 이번 지시의 §4 에 해당하나, 문구 정리에 구조 개편을 얹지 말라는 §10 단서를 따름. 실측으로 중복 메뉴가 나오면 그때 별건 플랜
- 디자인 토큰·레이아웃·색 — 이미 §1~4 와 가드 여섯이 봄
- 접근성 전수 감사 — 별건 (이번엔 새로 만지는 자리만 지킴)
- 없는 기능을 새로 만드는 일 — 이번 판은 **끊긴 것을 잇고 빠진 것을 세는** 판이다. 전수 조사로 나온 빠진 기능은 목록으로 남기고 심각도 순으로 고치되, 새 업무 기능 기획은 별건
- 거래 기록·감사 로그처럼 **고치면 안 되는 대상**에 수정·삭제를 붙이는 일 (조회·취소 기록·보관으로 처리하고 사유를 적음)

- 수치에서 목록으로 갈 때 **집계 조건(기간·상태·조직)이 유지되는지**를 표본으로 확인하고, 안 맞는 자리를 적음

### I11 심각도 순으로 고친다 — 데이터·권한·핵심 흐름 먼저
상태: 대기
모드: 경량
범위: I09·I10 이 뽑은 목록에서 정해짐 (항목 착수 시 플랜에 확정해 적음)
감사 기준:
- 고치는 순서가 **데이터 손상 → 권한 오류 → 핵심 흐름 중단 → CRUD 누락 → 상세 연결 → 상태 처리 → UX → 디자인 일관성** 임을 목록에 적고 그대로 진행
- 고친 자리마다 **UI → 창구 → 권한·검증 → 저장 → 결과 확인 → 화면 재반영 → 실패 처리** 가 이어지는 것을 확인 (F-8)
- 단추를 감추는 것으로 권한 검증을 대신하지 않음 — 서버에서 대상 접근 권한과 작업 권한을 확인
- 한 번에 다 못 고치면 **남은 것을 목록에 남기고 수를 보고에 적음** — 「남은 것」으로 범위를 줄이지 않음 (LOOP.md 8절)
- 보안: 권한과 창구를 만지므로 7절 「닿는 자리」에 걸림. 고친 자리마다 누가 부를 수 있는지 확인하고, 서비스롤을 쓰면 그 위에 사람 확인이 있는지 봄
의존: I10

### I12 대표 흐름을 실브라우저에서 끝까지 해 본다
상태: 대기
모드: 경량
범위: apps/web/e2e/ (신규 spec 1개)
감사 기준:
- 대표 흐름 하나를 10단계로 확인: ①정상 진입 ②데이터 생성 ③목록에서 찾기 ④상세 진입 ⑤수정 후 목록·상세 반영 ⑥새로고침·재접속 후 유지 ⑦주소 직접 입력·뒤로 가기 ⑧삭제 또는 비활성화 ⑨잘못된 입력·빈 결과·권한 제한 ⑩주요 화면 폭에서 잘림·겹침
- 브라우저 콘솔과 네트워크를 함께 보되 **오류 0 을 정상 판정의 근거로 쓰지 않음** — 기대한 데이터와 상태 변화가 실제로 일어났는지를 봄
- 검증은 **격리 서버(NEXT_DIST_DIR + 다른 포트)** 에서 하고, 만든 데이터는 **id 로** 되돌림 (제목으로 지우면 남의 것을 지운다)
- 운영 데이터 삭제·실제 결제·외부 발송을 하지 않음
- 확인 못 한 범위는 **못 했다고 적음** — 안 돌린 것을 통과로 적지 않음
- 보안: 실데이터를 건드리므로 시작 전 무엇을 만들고 무엇을 되돌리는지 적고, 되돌린 것을 확인
의존: I11
