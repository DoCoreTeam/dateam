## 목표
- 파일로 만든 견적이 실제 브라우저에서 조각을 만들고, 대조가 그 쪽을 여는 것을 눈으로 확인
- 쪽이 없는 원본(엑셀·한글)도 대조 화면에 세워, 「못 그려요」로 끝나지 않게 함

## 범위 밖
- 새 파일 형식 받기 (받는 목록은 그대로)
- 조각에 사람이 직접 그리거나 표시하는 기능

## 완료 정의
- pnpm tsc --noEmit, pnpm lint, pnpm test, pnpm build 통과
- 실브라우저에서 조각이 만들어지고 대조 왼쪽에 그 쪽이 뜨는 것을 스크린샷으로 남김
- 확인하며 만든 데이터는 id 로 되돌림
- 엑셀 원본을 붙인 견적에서 대조가 「못 그려요」가 아니라 읽은 내용을 보여 줌

## 항목

### I01 실브라우저에서 조각과 쪽을 눈으로 확인한다
상태: 통과
모드: 경량
범위: apps/web/e2e/quote-source-snapshot.spec.ts (신규), apps/web/e2e/_helpers.ts
감사 기준:
- 격리 서버(NEXT_DIST_DIR + :3100 + E2E_BASE_URL)에서 스펙이 통과한다
- 두 쪽짜리 PDF 로 견적을 만들면 첨부에 조각(png)이 생기는 것을 확인한다
- 대조를 열면 왼쪽에 조각이 뜨고 제목 옆에 「원본 n쪽」이 붙는 것을 스크린샷으로 남긴다
- 만든 견적과 첨부를 id 로 되돌리고, 되돌린 뒤 목록에 안 남는 것을 확인한다
- 보안: 새 창구·새 표 없음, 시험 계정은 기존 auth-state 를 쓴다
의존: 없음

### I02 쪽이 없는 원본도 대조 화면에 세운다
상태: 대기
모드: 경량
범위: apps/web/lib/crm/ui/quote-original.ts, apps/web/components/ui/crm/QuoteOriginalCompare.tsx, apps/web/components/ui/crm/quote-original-compare.module.css, apps/web/lib/crm/ui/quote-source-surface.test.ts
감사 기준:
- 엑셀 원본에서 대조 왼쪽이 「못 그려요」가 아니라 **그 파일의 표**를 그리는 단정이 있다
  (우리가 읽은 결과가 아니라 원본 자체를 그린다 — 대조 상대가 우리 해석이면 대조가 아니다)
- 그릴 수 없는 형식(한글 등)만 예전 안내로 떨어지는 단정이 있다
- 내려받기 길은 그대로 남는 단정이 있다
- 표 그리는 도구는 그 자리에서만 불러오는 단정이 있다 (견적 화면 전체가 무거워지면 안 된다)
- 보안: 셀 값을 HTML 로 조립하지 않고 글자로만 넣는다 (남이 심은 것을 실행하지 않는다, S4)
의존: I01
