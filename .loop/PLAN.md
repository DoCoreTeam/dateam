## 목표
- 시간 품목과 아닌 품목이 섞인 견적에서 모달 안내가 「시간당과 월 금액을 못 쓴다」고 거짓말하지 않는다
- 한 줄이라도 환산이 그려지면 그 사실에 맞는 말을 한다

## 범위 밖
- 합계 영역 환산이 섞인 견적에서 안 서는 규칙 자체 (의도대로임, 어느 줄에 곱해도 안 맞는 숫자를 안 적는다)
- 월 기준 시간 선택지 옆 미리보기 (섞이면 줄마다 달라 한 숫자를 적을 수 없다, 지금처럼 설명문으로 둔다)
- 비시간 품목에 「기간 총액」 이름이 붙는 것 (사용자 판단이 필요한 용어 문제, 보고만 함)
- 비고 열이 좁아 영문이 낱말 가운데서 끊기는 것 (이 판 전부터 있던 것)

## 완료 정의
- pnpm tsc --noEmit, pnpm test, pnpm build 통과
- 사용자 노출 문자열은 전부 i18n 키 사용
- 설정값은 env 추가 없이 DB 저장 + UI 관리 (해당 시)

## 참조
- LOOP.md 9절 U-N (빈 상태·오류·권한 없음은 서로 다른 상태, 실패를 위장하지 않는다)
- 실측 2026-10-05: 「식」 한 줄 + 「Hours 1440」 한 줄인 견적에서 견적서에는 시간당 금액이 인쇄되는데 모달은 「기간을 적거나 수량을 시간 단위로 적어야 시간당과 월 금액을 인쇄할 수 있어요」라고 적었다
