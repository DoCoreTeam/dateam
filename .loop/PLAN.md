## 목표
- 어제 실브라우저 점검에서 적어 둔 표시 이상 다섯이 화면에서 사라진다
- 고객에게 나가는 문서에 말이 안 맞는 이름이 안 붙고, 좁은 화면과 긴 비고에서도 읽힌다
- 저장 뒤 화면이 바뀌기 전까지 사용자가 「저장이 안 됐나」로 읽지 않는다

## 범위 밖
- 견적서 표를 좁은 화면에서 카드 모양으로 바꾸는 것 (고객에게 나가는 종이와 모양이 달라진다)
- 합계 영역 환산이 섞인 견적에서 안 서는 규칙 (의도대로임)
- pnpm build 가 힙 상한 없이는 죽는 것 (이 기계에 dev 서버가 넷 떠 있는 탓, 코드 문제가 아님)

## 완료 정의
- pnpm tsc --noEmit, pnpm test, pnpm build 통과
- 사용자 노출 문자열은 전부 i18n 키 사용
- 설정값은 env 추가 없이 DB 저장 + UI 관리 (해당 시)

## 참조
- LOOP.md 9절 U-N (빈 상태·로딩·오류는 서로 다른 상태) · F-N (UI 부터 저장 결과까지 잇는다)
- 실측 2026-10-05 (격리 dev :3310, 사용자 견적 DA-2026-1003-01 과 QA 견적)
  · 「식」 줄 아래 「기간 총액 500,000원」이 섬 (기간이 없는 줄에 기간이라는 이름)
  · 섞인 견적에서 730시간·720시간 옆이 빈칸
  · 비고 열 10% 라 「providin/g the special discoun/t」로 낱말 가운데서 끊김
  · 390px 에서 금액 열이 x=403 에서 시작해 첫 화면 밖 (표는 292/544 로 가로 스크롤됨)
  · 저장 뒤 +1초 +2초엔 옛 화면 그대로, +3초에 바뀜 (그동안 아무 표시 없음)
