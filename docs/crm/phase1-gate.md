## 한 줄

**영업 CRM은 지금 실제로 쓸 수 있다.** 회사·인물·딜을 넣고, 붙여넣기로 한 번에 만들고,

## 열려 있는 것 — T1-09 (HUMAN GATE)

**무엇을 못 하나**: 구글 계정을 연결하는 버튼이 화면에 없다.
그래서 메일이 자동으로 안 들어온다. 나머지는 전부 된다.

**왜 못 했나**: OAuth 클라이언트는 코드로 만들 수 없다. 사람이 GCP 콘솔에서
프로젝트를 만들고, 동의 화면을 내부(Internal)로 두고, 클라이언트 ID를 발급해야 한다.

**무엇이 있으면 되나**: 클라이언트 ID와 시크릿. 설정 화면에 등록하면
연결 버튼이 나타나고 T1-10의 실계정 스모크를 바로 돌릴 수 있다.
동기화 로직은 이미 다 있고 mock 픽스처로 14개 경로를 검증해 두었다 —
**바뀌는 것은 어댑터 하나뿐이다.**

## 만들면서 배운 것

### 실브라우저가 아니면 못 잡는 결함이 계속 나왔다

`tsc`·단위 테스트·리뷰가 전부 초록인데 화면은 안 되는 일이 이번 판에도 반복됐다.

- **딜을 성사로 바꿨는데 카드가 원래 칸에 남았다** — 상태만 바꾸고 단계를 안 옮겼다.
  상태와 단계는 같은 사실의 두 표현인데 코드가 하나만 바꿨다. (v0.7.496)
- **"30일 안에 되돌릴 수 있습니다"라고 써 놓고 되돌릴 길이 없었다** — 안내 문구만 있고
  복구 API도 휴지통 화면도 없었다. (v0.7.496)
- **AI가 실패하지 않았는데 "이해하지 못했습니다"라고 했다** — DB 쓰기 오류를
  모델 실패로 삼켜서, 진짜 원인이 사용자에게 닿지 않았다. (v0.7.498)
- **예산 상한이 0인데 화면은 "정상"이라고 했다** — 산술로는 안 넘었지만 AI는 첫 호출부터
  막히는 상태였다. 꺼진 것을 정상이라 부르면 사용자는 왜 안 되는지 영영 모른다. (v0.7.500)
- **병합을 되돌렸는데 그 쌍을 다시 합칠 방법이 사라졌다** — 후보가 MERGED로 남아
  목록에 안 뜨고, 다시 훑어도 "이미 있는 쌍"이라며 건너뛰었다. (v0.7.504)
- **0건인 단계에 "금액 미정"이라고 썼다** — 0건은 미정이 아니라 없는 것이다. (v0.7.507)

여섯 건 전부 **브라우저에서 눌러 보고** 나왔다. 코드가 맞는 것과 사용자가 쓸 수 있는 것은
다른 명제이고, 후자는 후자로만 증명된다.

### DB 제약이 코드의 전제를 무너뜨린 적이 있다

중복 탐지를 처음엔 "같은 도메인·같은 이메일이면 중복"으로 짰다.
그런데 스키마에 `(workspaceId, lower(domain))` 유니크가 걸려 있어서
**그런 중복은 애초에 만들 수 없었다** — 한 건도 못 잡는 죽은 코드였다.

실제 중복은 이렇게 생긴다: 같은 회사를 두 사람이 넣었는데 **한쪽이 도메인을 안 적었다.**
그래서 판정 축을 이름으로 옮기고, 도메인은 확신을 올리거나 내리는 근거로 썼다.
바꾸고 나니 운영 데이터에서 진짜 중복(`Konsttech` / `konst tech`)이 바로 잡혔다.

**규칙을 짜기 전에 DB가 이미 무엇을 막고 있는지 본다.**

### 집계 테스트는 모집단부터 갈라야 한다

리포트 테스트가 단독으로는 통과하고 함께 돌리면 실패했다.
옆 테스트가 같은 파이프라인에 딜을 만들어서다. 집계는 남의 데이터 한 건에도 판정이 흔들린다.
예산·리포트 테스트에 **전용 워크스페이스·전용 파이프라인**을 만들어 격리했다.

### 되돌릴 수 있게 만들면 승인 없이 갈 수 있다

병합은 남의 기록을 옮기는 무거운 작업이라 "승인 받고 하자"가 될 뻔했다.
소프트 삭제 + 스냅샷 + 30일 취소로 형태를 바꾸니 승인 없이 진행할 수 있었고,
운영 데이터로 직접 밟아 검증까지 했다(합쳤다가 되돌리고 원상 확인).

## 다음 판에 실제로 쓰면서 볼 것

1. **붙여넣기 등록이 실제 명함·메일 서명에서 얼마나 맞나** — mock 어댑터로는
   패턴을 아는 입력만 시험했다. 실모델을 붙이면 정확도가 다르게 나올 것이다.
2. **인박스 제안을 며칠이나 방치하게 되나** — 7일 TTL이 적절한지는 써 봐야 안다.
3. **중복 후보의 오탐률** — 이름 기준이라 동명 회사가 있으면 뜬다. 몇 번 "아니다"를
   누르게 되는지 보고 임계를 조정한다.
